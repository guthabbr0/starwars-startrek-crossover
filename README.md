# Stellar Rift: Crossover War

A Three.js space-combat game with room-based WebRTC multiplayer.

This repository is being initialized from the source prototype and will include automated gameplay tests and performance reports. Do not treat a passing syntax check as a verified deployment.

## Delivery status

- Live deployment: not yet verified.
